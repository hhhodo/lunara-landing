# SOOM Landing Page

전분(starch) 소재로 성형한 인센스 스틱 브랜드 SOOM의 원페이지 랜딩. 브랜드명은 영문(SOOM), 본문
콘텐츠는 한글로 작성. (저장소/폴더명은 최초 빌드 당시 브랜드였던 `lunara-landing`을 그대로 유지 —
아래 그리드/토큰 관련 기록은 LUNARA로 빌드하던 시점의 내용이며 구조적으로는 그대로 유효합니다.)

## 브랜드 피벗 (LUNARA → SOOM)

라이프스타일 콘텐츠 스튜디오(LUNARA)에서 전분 인센스 스틱 브랜드(SOOM)로 전체 카피와 아이콘을
교체했습니다. 그리드/레이아웃 구조는 그대로 두고 의미만 바꿨습니다:
- Hero: 워드마크 LUNARA→SOOM, eyebrow "Lifestyle Content Studio"→"Starch-Based Incense Studio"
- Featured: "선택된 작업물" 5개 → 시그니처 향 컬렉션 5개(우디 시더우드 등, 연소시간 표기)
- Philosophy: 촬영/콘텐츠 관련 니즈 카드 5개 → 인센스 구매 니즈 5개(무합성향료·저재·잔향 지속 등),
  아이콘도 카메라/아카이브 박스 등에서 잎사귀/인센스 연기/시계 나선/선물상자/향 배리에이션으로 교체
- History: 콘텐츠 스튜디오 연혁 → 전분 성형 특허·친환경 인증 등 인센스 브랜드 연혁
- Portfolio: "Selected Works"(광고주 작업물) → "Where to Find SOOM"(입점처/컬래버 공간)
- Contact: 카테고리를 브랜드필름/공간화보 등에서 입점문의/도매문의/협업제안으로, 예산범위 필드를
  예상 주문 수량으로 교체
- Footer/메타 태그: 이메일·인스타그램·비즈니스 설명 전부 교체

## 그리드 정렬 재작업 (Featured/History 가로 스크롤 트랙)

이전까지 Featured/History 카드 폭을 "트랙 안에 몇 개 보이게"(예: `calc(100%/3.5)`) 기준으로 잡아서,
트랙의 시작점(1컬럼 인셋)만 실제 라인과 맞고 그 이후 카드 경계는 전부 어긋나 있었습니다. 카드 폭을
트랙 자기 자신의 폭이 아니라 **실제 페이지 그리드 컬럼의 정수배(vw 단위)**로 고정하고 `gap:0`으로
바꿔서, 카드가 몇 개든 모든 경계가 실제 세로 라인과 겹치도록 재계산했습니다:
- Featured 카드: `25vw` (페이지 12컬럼 기준 3컬럼)
- History 카드: `33.333vw` (페이지 12컬럼 기준 4컬럼)

이미지가 없는 하위 그리드(Contact 6-6 라벨, Philosophy 9-3 텍스트 블록 등)는 라인 정렬이 중요하지
않아 기존 로컬 12등분 그리드를 그대로 유지했습니다.

## 레퍼런스 취득 경로

1차 빌드는 루트 프레임(`81:2182`)을 한 번의 `get_design_context` 호출로 받으려다 응답이 100k+
문자에서 잘려, 서브에이전트가 정리한 요약 수치만으로 작업했습니다. 그 결과 히어로 요소 순서,
History 6개년 중 3개 누락, 테스트모니얼 내용 임의 작성, Contact 배경색·필드 구성, Footer 구조가
전부 실제 Figma와 달라졌다는 피드백을 받고 **섹션별로 `get_design_context`를 개별 호출**해
node `81:2183`(Hero), `81:1498`(Philosophy/니즈 카드), `81:3558`(History), `81:4621`(Portfolio),
`81:2354`(Contact), `81:3221`(Footer)의 정확한 마크업·좌표·색상·텍스트를 다시 확보해 전면
재작업했습니다.

## 사이트 전역 12컬럼 라인과 이미지 정렬 (`.grid--10`)

페이지 전체에 12컬럼짜리 세로/가로 라인 오버레이(`.page-lines`)가 항상 깔려 있는데, 각 섹션이
`.bleed`(10컬럼 폭으로 인셋된 박스) 안에서 다시 `.grid`(12등분)를 쓰면 로컬 컬럼 폭이 실제 페이지
컬럼 폭보다 좁아져서 카드/이미지 경계가 실제 라인과 전혀 겹치지 않았습니다. 이미지가 있는 섹션
(Featured/History 상단/Portfolio)은 `.grid--10`(10등분)으로 바꿔, 로컬 그리드 라인이 실제 페이지
라인과 정확히 일치하도록 재계산했습니다 — `.bleed`가 정확히 10개 페이지 컬럼 폭이므로 10등분하면
로컬 1컬럼 = 실제 페이지 1컬럼이 됩니다. Contact 폼 내부 6-6 라벨 페어, Philosophy 9-3 텍스트 블록처럼
이미지가 없는 하위 그리드는 라인 정렬이 중요하지 않아 기존 12등분 로컬 그리드를 그대로 유지했습니다.

## 원본 대비 제외한 요소 ("페이지 이동으로 보이는 모든 요소는 빼줘" 지시에 따름)

1. **최상단 nav bar** (Artists / Productions / Contact 앵커 링크) — 페이지 내비게이션이라 전체 제외.
2. **Featured 섹션 스크롤 진행률 tick 인디케이터**(27개 눈금) — 페이지네이션 점과 동일한 역할이라 제외,
   정적 3카드 그리드로 대체.
3. **Philosophy 섹션의 "01 / 05" 스텝 카운터** — 캐러셀 페이지네이션이라 텍스트만 제외, 니즈 카드
   콘텐츠 자체는 원본 5장 중 앞 2장을 그대로 정적 스택으로 유지.

그 외 모든 텍스트·구조·색상·필드 구성은 실측값을 그대로 따랐습니다. 치트시트의
"캐러셀·페이지네이션·화살표 버튼 금지" 하드 룰과도 방향이 일치합니다.

## 디자인 토큰 준수

- `css/styles.css`는 원본 디자인 킷 그대로 두고 수정하지 않았습니다 (EDITORIAL 프리셋, 본문 20px).
- 원본이 다크 모노톤(`#1d1d1d` 배경, 흰 텍스트)이라 `css/site.css`에 `--brand-bg`, `--brand-border`,
  `--brand-line`, `--brand-text-subtle` 4개의 `--brand-*` 커스텀 프로퍼티만 추가했습니다 — 레퍼런스가
  실측으로 제공한 값이므로 "임의 HEX 금지" 규칙의 예외로 취급했습니다.
- 폰트 크기는 실측값(히어로 워드마크 ~100px, 섹션 헤딩 ~90px, 카드 타이틀 22px, 메타 17px, 폼 라벨
  16px)을 가장 가까운 기존 타입 스케일 토큰에 매핑했습니다: 히어로 → `--fs-display-lg`(102),
  섹션 헤딩 → `--fs-display-sm`(80), 카드 타이틀 → `--fs-body-1`(20, bold), 메타/라벨 →
  `--fs-body-2`(18). 자간·행간·폰트 크기 모두 `var(--token)`만 사용, 임의 px/em 없음.
- Border-radius는 실측 그대로 전 구간 `--radius-0`(sharp corner).
- 이미지 영역은 전부 `.img`(= `#d9d9d9`, `--color-placeholder`)로 채웠습니다 (사용자 지시 사항).

## 스택

- `index.html` — 시맨틱 마크업, Variant Memo + Layout Declaration 주석 포함

- `css/site.css` — LUNARA 브랜드 컴포넌트
- `js/main.js` — 스크롤 reveal (캐러셀 없음)
- `.github/workflows/deploy.yml` — GitHub Pages 배포 (Actions)
